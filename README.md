# MoodBot — Telegram-бот для дневника настроения

Простой Telegram-бот для ежедневной фиксации своего состояния.

---

## Структура проекта

```
moodbot/
├── bot.py               # Точка входа
├── config.py            # Загрузка токена из .env
├── database/
│   └── db.py            # Работа с SQLite
├── handlers/
│   ├── start.py         # /start, помощь, навигация
│   ├── checkin.py       # FSM-сценарий заполнения записи
│   ├── history.py       # История записей
│   └── stats.py         # Статистика за 7 дней
├── keyboards/
│   └── keyboards.py     # Все клавиатуры
├── states/
│   └── states.py        # FSM-состояния
├── requirements.txt
├── .env.example
└── README.md
```

---

## Локальный запуск

```bash
# 1. Клонируй или скачай проект
# 2. Установи зависимости
pip install -r requirements.txt

# 3. Создай .env на основе примера
cp .env.example .env
# Вставь свой токен в .env (и опционально DEEPSEEK_API_KEY)

# 4. Запусти
python bot.py
```

---

## Возможности

| Функция            | Описание                                      |
|--------------------|-----------------------------------------------|
| /start             | Приветствие и главное меню                    |
| 📝 Заполнить запись | Пошаговый чек-ин (настроение, энергия и др.) |
| 📋 История          | Последние 7 записей                           |
| 📊 Статистика       | Средние показатели за 7 дней                  |
| ❓ Помощь           | Краткая справка                               |

---

## Примечания

- База данных `moodbot.db` создаётся автоматически в корне проекта при первом запуске.
- Одна запись в день на пользователя: повторный чек-ин обновляет, а не дублирует запись.
- FSM-состояния хранятся в памяти (сбрасываются при перезапуске бота). Это нормально для MVP.
