# MoodBot — Telegram-бот для дневника настроения

Простой Telegram-бот для ежедневной фиксации своего состояния.

---

## Структура проекта

```
moodbot/
├── bot.py               # Точка входа
├── config.py            # Загрузка токена из .env
├── database/
│   └── db.py            # Работа с SQLite
├── handlers/
│   ├── start.py         # /start, помощь, навигация
│   ├── checkin.py       # FSM-сценарий заполнения записи
│   ├── history.py       # История записей
│   └── stats.py         # Статистика за 7 дней
├── keyboards/
│   └── keyboards.py     # Все клавиатуры
├── states/
│   └── states.py        # FSM-состояния
├── requirements.txt
├── .env.example
└── README.md
```

## Запуск в Replit

### 1. Создай Repl

- Зайди на [replit.com](https://replit.com) и создай новый Repl типа **Python**.
- Загрузи все файлы проекта (через кнопку Upload или перетащи папку).

### 2. Установи зависимости

В **Shell** выполни:

```bash
pip install aiogram==3.7.0 python-dotenv==1.0.1
```

Или создай файл `pyproject.toml` / используй кнопку **Packages** в Replit и добавь:
- `aiogram`
- `python-dotenv`

### 3. Добавь токен бота

- Получи токен у [@BotFather](https://t.me/BotFather) в Telegram.
- В Replit открой раздел **Secrets** (замок в левой панели).
- Добавь секрет: ключ `BOT_TOKEN`, значение — твой токен.

> Либо создай файл `.env` в корне проекта (для локального запуска):
> ```
> BOT_TOKEN=твой_токен_здесь
> ```

### 4. Настрой точку входа

В файле `.replit` (или в настройках Run) убедись, что команда запуска:

```
python bot.py
```

### 5. Запусти бота

Нажми кнопку **Run** в Replit.

В консоли появится:
```
База данных готова.
Бот запущен.
```

Открой своего бота в Telegram и отправь `/start`.

## Локальный запуск

```bash
# 1. Клонируй или скачай проект
# 2. Установи зависимости
pip install -r requirements.txt

# 3. Создай .env на основе примера
cp .env.example .env
# Вставь свой токен в .env

# 4. Запусти
python bot.py
```

## Возможности

| Функция            | Описание                                      |
|--------------------|-----------------------------------------------|
| /start             | Приветствие и главное меню                    |
| 📝 Заполнить запись | Пошаговый чек-ин (настроение, энергия и др.) |
| 📋 История          | Последние 7 записей                           |
| 📊 Статистика       | Средние показатели за 7 дней                  |
| ❓ Помощь           | Краткая справка                               |

## Примечания

- База данных `moodbot.db` создаётся автоматически в корне проекта при первом запуске.
- Одна запись в день на пользователя: повторный чек-ин обновляет, а не дублирует запись.
- FSM-состояния хранятся в памяти (сбрасываются при перезапуске бота). Это нормально для MVP.
