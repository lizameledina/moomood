# MoodBot — Telegram-бот для дневника настроения

Простой Telegram-бот для ежедневной фиксации своего состояния.

---

## Структура проекта

```
moodbot/
├── bot.py                  # Точка входа
├── config.py               # Загрузка конфигурации из .env
├── constants.py             # Общие константы (MOOD_LABELS, TAG_LABELS)
├── database/
│   └── db.py               # Работа с SQLite
├── handlers/
│   ├── start.py            # /start, помощь, навигация
│   ├── checkin.py          # FSM-сценарий заполнения записи
│   ├── history.py          # История записей
│   ├── stats.py            # Аналитика (графики, связи, инсайты)
│   └── ai.py               # AI-поддержка (DeepSeek)
├── keyboards/
│   └── keyboards.py        # Все клавиатуры
├── states/
│   ├── states.py            # FSM-состояния чек-ина
│   └── ai_states.py         # FSM-состояния AI-чата
├── utils/
│   ├── analytics.py         # Построение текстовой аналитики
│   └── deepseek_client.py  # HTTP-клиент для DeepSeek API
├── requirements.txt
├── .env.example
└── README.md
```

---

## Локальный запуск

```bash
# 1. Клонируй или скачай проект
# 2. Установи зависимости
pip install -r requirements.txt

# 3. Создай .env на основе примера
cp .env.example .env
# Вставь свой токен в .env (и опционально DEEPSEEK_API_KEY)

# 4. Запусти
python bot.py
```

## Возможности

| Функция              | Описание                                              |
|----------------------|-------------------------------------------------------|
| /start               | Приветствие и главное меню                            |
| Заполнить запись      | Пошаговый чек-ин (настроение, энергия, стресс, сон)  |
| История              | Последние записи                                      |
| Статистика           | Аналитика: sparkline-графики, связи, инсайты          |
| AI-поддержка         | /ai — начать разговор, /ai_off — выключить            |
| /timezone            | Настройка часового пояса                              |

---

## Примечания

- База данных `moodbot.db` создаётся автоматически в корне проекта при первом запуске.
- Можно делать несколько чек-инов за день (они сохраняются отдельно).
- FSM-состояния хранятся в памяти (сбрасываются при перезапуске бота).
- AI-функция требует `DEEPSEEK_API_KEY` в `.env`.
